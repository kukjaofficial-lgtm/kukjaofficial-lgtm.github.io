# How to post a weekly discussion

1. Open https://app.pagescms.org and sign in with your GitHub account.
2. Choose the repository "kukjaofficial-lgtm.github.io".
3. In the left menu, open "토론 기록 (한국어)" and click "Add an entry".
4. Fill in:
   - 제목: the title of the discussion
   - 회차: the week number only (for example 12)
   - 모임 날짜: the date of the session
   - 분류, 발제자, 요약, 대표 사진: optional
   - 본문: the summary of the discussion. Use headings and bullet lists freely.
5. Click "Save". The page appears on the website about 1-2 minutes later.
6. Open "討論の記録 (日本語)" and do the same in Japanese.
   IMPORTANT: use the SAME week number in both languages.
   That is how the "read in the other language" link finds its pair.

## Other things you can edit
- 홈페이지 설정 / ホームページ設定: slogan, introduction, next session,
  the three themes, club email and Instagram link (contact buttons appear
  once you fill these in).
- 소개 페이지 / 紹介ページ: the About page in each language.

## Deleting the sample posts
The posts marked (예시) / （例） are examples. Delete them in the editor
once you have published your first real post.

## Handover
New officers: ask the current president to invite you as a collaborator
on the GitHub repository (Settings > Collaborators). Then you can sign in
to Pages CMS with your own GitHub account.
